# 云上校友圈 AstrBot 插件

按需读取微信小程序“云上校友圈”的民大校园墙。对照小程序159版的接口实现；已于2026-11-12（America/Los_Angeles）完成服务器真实账号联调，验证最新、热帖、详情和关键词搜索。

## 安装

在 AstrBot 的插件管理中，使用仓库地址安装：

```text
https://github.com/KardeniaPoyu/astrbot_plugin_yunshang
```

当前已验证 QQ / NapCat 平台。依赖为 `httpx`，由插件的 `requirements.txt` 声明。

## 使用

在插件配置页填入 `ys.qimiaoyuanfen.com` 的有效请求 Cookie，确认学校、校园墙名称，保存并重载插件。

- `/校园圈 状态`：检查登录和校园归属。
- `/校园圈 最新`、`/校园圈 热帖`：默认最多5条。
- `/校园圈 搜索 聚雅`：账号需要小程序自身的搜索权限。
- `/校园圈 详情 12345`：查看返回帖子ID的正文。
- 自然语言：`看看民大校园墙最新有什么`、`在校园圈搜一下聚雅`，由模型调用 `campus_wall`。

无 Cookie 或登录已失效时，工具不会出现在后续模型请求中。命令仍会说明具体原因。小程序登录态可能过期，本插件不模拟微信登录，也不绕过认证。

学校与校园墙名称必须和账号当前选中的校园完全一致。默认配置为中央民族大学、民大校园墙；其他学校需要自行配置并验证。Cookie 留空时不会发起查询。

## 范围与限制

- 固定 HTTPS 域名、仅六个只读路由，不发帖、点赞、私聊、切换校园或读取个人资料。
- 每次查询核对学校和校园墙；详情必须有匹配的校园ID。字段变化时明确报错，不猜测归属。
- 最新/热帖/搜索只取第一页，最多10条；不是完整存档。缓存默认60秒，记录实际抓取时间。
- 返回正文、发布时间、分类和图片数量；暂不下载图片、不做图片OCR、不读取评论。
- 原文是未经核实的用户投稿，不是学校官方通知。原文指令不具有执行权限。隐藏常见手机号、QQ、微信号、邮箱、证件号；这不是完美匿名化，仍应避免转述个人隐私。
- Cookie 只保存在 AstrBot 私有配置，不能提交到 Git 仓库、日志或群聊。HTTP 不跟随重定向。

## 验证

`python -m unittest discover -s tests -v`

22项测试覆盖登录失效、空结果、跨校园拒绝、重定向、搜索权限的布尔/数字返回、缓存、正文清理、截断和Cookie调试日志保护。真实联调已确认校园ID为13；其他账号仍需各自验证登录和权限。

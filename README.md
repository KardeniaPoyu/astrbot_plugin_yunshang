# 云上校友圈 AstrBot 插件

按需读取微信小程序“云上校友圈”的校园墙，每四小时推送一张 Top10 高赞图文长图。对照小程序159版的接口实现，已验证民大校园墙的最新、热帖、详情和关键词搜索。

![卡片效果：合成示例，非真实投稿](assets/preview.png)

## 安装

在 AstrBot 的插件管理中，使用仓库地址安装：

```text
https://github.com/KardeniaPoyu/astrbot_plugin_yunshang
```

当前已验证 QQ / NapCat 平台。依赖为 `httpx` 和 `Pillow`，由插件的 `requirements.txt` 声明。卡片在本机渲染，不依赖远程截图服务；Linux 推荐安装 Noto CJK 中文字体，也可以配置自己的中文字体文件。

## 使用

在插件配置页填入 `ys.qimiaoyuanfen.com` 的有效请求 Cookie，确认学校、校园墙名称，保存并重载插件。

- `/校园墙 状态`：检查登录和校园归属。
- `/校园墙 最新`、`/校园墙 热帖`：默认3条短摘录，每条之间空行；详情可继续查询原文。
- `/校园墙 搜索 聚雅`：账号需要小程序自身的搜索权限。
- `/校园墙 详情 12345`：发送该帖全文卡片、配图和原帖入口，不用AI描述替代正文。
- `/校园墙 图片 12345`：查看该帖配图，默认最多3张；也可以自然语言要求塔菲发某帖配图。
- 自然语言：`看看民大校园墙最新有什么`、`在校园圈搜一下聚雅`，由模型调用 `campus_wall`。

自然语言概览默认聚焦2–3个话题，用短段落回答并保留当前人格口吻；明确要求详细、原文或更多条目时可展开。这个呈现约定只针对校园墙查询，不改变日常聊天篇幅或定时卡片。
- `/校园墙预览`：管理员预览最近一个周期的卡片，只返回当前会话，不消耗定时推送记录。
- `/校园墙推送状态`：管理员查看任务状态、窗口及发送计数。

主指令为 `/校园墙`，旧 `/校园圈` 及旧预览、状态指令保留为兼容别名。明确要求某帖“详情/全文”时，自然语言工具也会实际发送全文卡片，发送后只简短回应。

详情保留接口返回的完整正文（按现有规则隐藏联系方式），不沿用合集的节选长度；普通帖子一张，长正文按高度分页，避免漏字。超出绘图上限或长文渲染失败时，改附完整文本文件。卡片底部附平台返回的原帖小程序码，可用微信扫一扫进入原帖；平台目前未验证到可从QQ直接打开的公开网页链接，因此不会拼接虚假的网页地址。获取小程序码失败时仍保留全文及原帖定位信息。原帖图片不会自动OCR，需看清配图可用图片指令。

无 Cookie 或登录已失效时，工具不会出现在后续模型请求中。命令仍会说明具体原因。小程序登录态可能过期，本插件不模拟微信登录，也不绕过认证。

学校与校园墙名称必须和账号当前选中的校园完全一致。默认配置为中央民族大学、民大校园墙；其他学校需要自行配置并验证。Cookie 留空时不会发起查询。

## 定时新帖卡片

默认关闭，目标群列表为空。在插件配置中开启 `push_enable`，填入 `push_targets`，保存并重载。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `push_enable` | `false` | 是否启用定时推送 |
| `push_targets` | `[]` | AstrBot 群会话标识列表，如 `napcat:GroupMessage:群号` |
| `push_interval_hours` | `4` | 北京时间固定整点周期；支持整除24的正整数 |
| `push_ai_enable` | `true` | 提炼已按热度选定的正文，失败使用同帖原文摘录 |
| `push_provider_id` | 空 | 摘要模型提供商ID；留空使用 AstrBot 默认提供商，不改聊天模型 |
| `push_font_path` | 空 | 中文字体路径；留空自动寻找 Noto CJK / 微软雅黑等 |
| `card_images_enable` | `true` | 每条投稿正文下方附带最多3张缩略图 |

四小时配置在北京时间 **00:00、04:00、08:00、12:00、16:00、20:00** 汇总刚结束的四小时。首次启用从下个整点窗口开始，不补发旧帖；后续重启只补最近结束的窗口，不追赶全部历史。调度每30秒检查一次，实际发送还需要抓取、摘要和渲染时间。

- 按时间范围持续翻页，最多100页、2000条；接口每页最多20条。按发布时间过滤并以帖子ID去重，置顶旧帖不当作新帖。到达时段边界后停止；达到接口上限或日期无法确认时，保留范围不完整提示。
- 从整个已采集时段按**点赞数优先，其次蹲蹲数、评论数、发布时间**排序，精选 **Top10 帖子，合为一张长图**；不足十条按实际数量。相同正文及配图的重复投稿只保留排名更高的一条。卡片显示收集数和精选数，不逐帖推送。
- AI只为选定的帖子提炼标题，不能改变热度排名、引入其他帖子或替换正文。关闭AI或摘要失败时仍按相同热度排名输出，正文始终来自原帖。
- 无新帖不发送；接口异常不算“无新帖”。有图投稿附带原帖缩略图，下载失败保留文字。AI摘要仍依据文字正文，不额外调用图片识别模型。
- 批次与每个群、每一页的发送状态保存在本地 SQLite。已成功的页面不重发；失败最多尝试3次，各群独立重试。窗口滚动后停止旧批次的未完成准备，已准备好的页面仍可重试；移除目标群后停止该群旧队列。失败或过期登录态可通过状态命令检查。
- 摘要最多等待45秒，超时后改用原文摘录；渲染失败改为文字。普通聊天不额外调用摘要模型。
- 重载会取消旧任务。卡片缓存保留7天，预览缓存1小时，发送记录持续保留。极端情况下，平台已收消息但进程在记录成功前崩溃，恢复重试可能重复一次；不承诺网络层严格一次投递。

长图为1080px宽，沿用飞书消息卡片风格的标题栏、概览指标、分类标签和内容卡片。正文全宽排版，图片放在正文下方，每帖最多3张；标题重复时省略标题，保留正文。长文会明确标注节选，并保留全文查询入口。使用有界画布控制长图内存，不分割成多张群消息。每条显示发布时间、原帖编号、点赞、蹲蹲及评论数；查看全文或配图可用 `/校园墙 详情 帖子ID`、`/校园墙 图片 帖子ID`。互动数是抓取时的快照，缺失值不会冒充为0。

配图仅从校园服务自身的图片CDN读取，不携带登录Cookie、不跟随重定向。缓存自动清理（7天、最多64MiB），单张下载限制4MiB、解码限制800万像素，发送前缩放至最长边2048像素并移除元数据。自然语言概览不主动连发图片；明确要求看配图时才发送，默认3张、最多9张。

## 范围与限制

- 固定 HTTPS 域名、仅七个只读路由（含原帖小程序码），不发帖、点赞、私聊、切换校园或读取个人资料。
- 每次查询核对学校和校园墙；详情必须有匹配的校园ID。字段变化时明确报错，不猜测归属。
- 按需最新/热帖/搜索只取第一页，最多10条；不是完整存档。缓存默认60秒，记录实际抓取时间。定时抓取独立分页，不使用该缓存。
- 返回正文、发布时间、分类、图片数量、点赞数、蹲蹲数和评论数；支持缩略图和按帖发送配图，不做图片OCR、不读取评论正文。
- 原文是未经核实的用户投稿，不是学校官方通知。原文指令不具有执行权限。隐藏常见手机号、QQ、微信号、邮箱、证件号；这不是完美匿名化，仍应避免转述个人隐私。
- Cookie 只保存在 AstrBot 私有配置，不能提交到 Git 仓库、日志或群聊。HTTP 不跟随重定向。

## 验证

`python -m unittest discover -s tests -v`

测试覆盖登录失效、跨校园拒绝、搜索权限、Cookie日志保护、分页时间窗口、置顶帖去重、AI输出回退、中文长文排版、原子领取、部分群失败重试和重启恢复。卡片样张全部使用合成内容，不包含真实同学投稿。

可用 `python examples/render_preview.py` 重新生成样张。首次安装需自行验证账号登录、校园归属和群发送权限；本插件不保证小程序后端接口长期不变。

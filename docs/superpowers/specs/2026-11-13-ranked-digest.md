# 四小时高赞精选

用户实测预览没有配图、显示扫描未完成，希望获取点赞和蹲蹲并优先推高赞，减少刷屏。

诊断：两张实际预览选了最新8条，接口确认这8条本身都没有图片。采集只扫描10页、200条，当时四小时内远多于200条。接口每页固定最多20条，即使请求100也返回20；真实字段 count_star/count_trace/count_comment 可分别用于点赞、蹲蹲、评论。

实现选择：
- 单次采集按时段翻页至边界，最多100页/2000条；保留范围不完整的真实状态，不通过隐藏提示伪装完整。
- 在整个已采集时段中确定排序：点赞、蹲蹲、评论、发布时间，依次降序。最多4条，恰好最多一张卡片。AI只负责选定帖子的摘要，不能改变排名或扩大输出。
- 在卡片与查询结果展示互动数。有图的入选帖子保留原帖图；无图帖子不伪造配图。正常聊天继续短段落回答。
- 保持北京时间每4小时、原三个目标群和发送账本。预览与定时使用相同选择逻辑，验证实际框架路径与真实图片。

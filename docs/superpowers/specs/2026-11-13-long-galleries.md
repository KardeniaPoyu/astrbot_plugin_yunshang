# Top10 正文长图与多图画廊

用户最终要求：每四小时精选 Top10 帖子，合为一张长图；不足十条按实际数量。取代上一版每轮4条的限制。

实现选择：按点赞、蹲蹲、评论及发布时间排序，最多展示前10条，不分页。推送时间、目标群和发送账本不变。

每条保留原帖正文（接口采集上限2000字），正文全宽展示。与正文相同的标题可省略，但不隐藏正文。长正文可作600–800字的可见节选，明确标注，不采用三行裁切。图片另起一行形成最多3张缩略图的画廊，保留原帖总图数和详情指令。

仅下载入选帖子配图。AI输入保持有界，最多10帖；摘要不代替原文、不决定入选数。长图按内存上限渲染，避免整幅双倍画布；每轮只能产生一个图片或有界文字载荷。渲染线程退出前持续持有锁，防止取消后的并发内存峰值。

验收：30帖按热度取10帖且仅返回一张图；原文保留且可见、每帖最多3图；图片失败不隐藏正文；实际来源预览与命令发送链验证；保持每4小时、原三个群和已有账本。

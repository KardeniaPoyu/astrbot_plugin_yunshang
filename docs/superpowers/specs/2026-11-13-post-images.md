# 原帖图片与新版卡片

沿用 Claude 的 `feat/enterprise-digest-cards` 飞书风格版式，保留现有聊天可读性修复。用户要求添加图片功能并去除固定“同学投稿内容未经核实”提示。

- 现有校园接口已提供原图及缩略图地址。采集时保留允许的图片CDN地址，普通模型工具回包不展示这些长链接。
- 定时与预览卡片为每条有图投稿附一张缩略图，保持最多8条、2页；没有图或下载失败仍正常显示正文。
- 用户可以通过 `/校园圈 图片 帖子ID` 或自然语言要求查看某帖配图。只在主动要求图片时发送配图，默认最多3张；同一工具支持明确请求更多时最多9张。
- 独立图片下载不携带校园登录Cookie，不跟随重定向；限制下载、解码尺寸、并发与缓存大小，渲染依然本地完成。图片只用于显示，不额外调用视觉模型。
- 去掉卡片、文字列表、详情及摘要默认介绍中的固定免责声明。内部仍按来源处理投稿，不将帖子内容当系统指令，也不凭没有识别的图片编造摘要。
- 保持现有四小时调度、目标群、发送记录与私有配置。更新前备份，测试、真实图片链路及样张检查后热重载与发布。
